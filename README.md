# ☕ Java Beginner Practice Repository

This repository is designed for **Java beginners and freshers** who want to build **strong fundamentals**, practice daily, and prepare for **technical interviews / off-campus drives**.

It follows a **day-wise structured approach** with clear practice questions and separate solution notes.

---

## 📌 What This Repository Contains

- ✅ Daily Java Practice Questions (Beginner Friendly)
- ✅ Separate Solutions for Reference
- ✅ Interview-oriented problems
- ✅ Covers Core Java, OOPS, Collections, and Exception Handling

---

## 🗓 Daily Practice Plan

### 🔹 Day 1 – Java Basics
- Hello World program
- Printing numbers
- Sum of two numbers
- Even/Odd check
- Largest of three numbers

### 🔹 Day 2 – Loops
- Natural numbers
- Multiplication table
- Factorial
- Reverse a number
- Count digits

### 🔹 Day 3 – Patterns
- Star patterns
- Number patterns
- Pyramid patterns

### 🔹 Day 4 – Arrays
- Array declaration & traversal
- Sum of elements
- Largest element
- Reverse array
- Even/Odd count

### 🔹 Day 5 – Strings
- String length
- Reverse string
- Palindrome check
- Vowel count
- String comparison

### 🔹 Day 6 – Methods & OOPS
- Methods
- Class & object
- Encapsulation
- Inheritance
- Method overloading

### 🔹 Day 7 – Collections & Exception Handling
- ArrayList
- Set (remove duplicates)
- HashMap
- try-catch
- Custom exception

3. Spend 60–90 minutes per day
4. Verify answers using Solutions PDF
5. Practice explaining your code aloud
